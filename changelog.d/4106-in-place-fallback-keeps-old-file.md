- **生成物入口退回就地寫入時，寫到一半失敗不再留下新內容的前半段（[#4106](https://github.com/vencil/Dynamic-Alerting-Integrations/issues/4106)）**：`write_repo_artifact` 不能原子取代時（既有檔有多個 hard link、屬於別人、帶延伸屬性、目錄不可寫），會退回就地寫入。現在會先把新內容完整寫進同目錄的暫存檔：撞到檔案大小上限、空間或配額時，在動到目標之前就結束（rc 2），舊檔保持原樣。暫存檔寫不進去（目錄不可寫）時，改為先讀出舊內容，寫失敗就經同一個 descriptor 寫回（不依路徑再開一次，期間被換上的別的檔不會被蓋掉）。連寫回也失敗時留下空檔，與 operator 入口相同，原本會留下新內容的前半段。目標原本不存在時（含懸空 symlink 指向的位置）改為獨佔建立，寫失敗時經同一個 descriptor 把這次建出的檔清空（不依路徑刪除，留下空檔）；別的程序在這期間建立或換上的同名檔不會被寫入或刪除。pipe、終端機等非一般檔（例如 `/dev/stdout`）照舊直接寫，不預檢也不讀舊內容。成功路徑的輸出不變；磁碟剛好只夠就地寫入的情況現在會被拒絕（沿用 #2082「寧可失敗、保留舊檔」）。寫到一半被 kill 時仍可能留下部分內容，WARN 已改寫明這點。
