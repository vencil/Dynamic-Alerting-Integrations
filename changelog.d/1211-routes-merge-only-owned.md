- **⚠️ BREAKING：`generate-routes` 移除 routing fragment 模式，三種輸出模式共用同一個合併，base 只當來源（[#1211](https://github.com/vencil/Dynamic-Alerting-Integrations/issues/1211)）**：不帶模式旗標改為結束碼 2——照 fragment 檔頭接在自有路由後面時，Watchdog 進客戶預設頻道、custom／sentinel 叫醒客戶 NOC。改用新增的 `--output-alertmanager --base-config <你自己的設定>` 或 `--output-configmap`；`--apply` 也從「整個取代 `route.routes`」改為同一個合併。輸出＝合併（來源, conf.d），順序是平台路由與 enforced NOC → 你的路由 → 租戶路由；conf.d 改了就拿同一份來源再跑。產物第一行是 `# GENERATED by da-tools generate-routes` 標記；base 帶這一行、或含 `tenant-*`／`platform-enforced*` receiver（像本工具的輸出）結束碼 1，`-o` 或 `--findings-json` 指向 base 結束碼 2；貼過 fragment 的設定要先刪掉貼進去的部分。`--apply` 的來源存在 ConfigMap 的 `alertmanager.base.yml`。`watchdog-heartbeat` 沒接 integration 時報 `watchdog_undelivered`：WARN，你自己的 base 加 `--strict` 時 ERROR、結束碼 1。
